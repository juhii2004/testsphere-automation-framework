# 🚀 TestSphere: Unified Test Automation Framework

## 📌 Overview
TestSphere is a lightweight unified test automation framework integrating UI and API testing with centralized execution and reporting.

---

## 🧩 Tech Stack
- Selenium WebDriver (UI Automation)
- Rest-Assured (API Testing)
- Cucumber BDD (Gherkin)
- TestNG (Execution)
- Allure Reports (Reporting)
- Java + Maven

---

## 🔥 Key Features
- Tag-based execution (@ui, @api)
- Parallel test execution
- Thread-safe WebDriver using ThreadLocal
- Page Object Model (POM)
- Unified reporting with Allure

---

## ▶️ How to Run

mvn clean test
